# Emergent Handoff

## Goal

Turn the approved structural scaffold into a polished frontend prototype while
keeping all data mocked and replaceable.

## Initial design scope

- Homepage
- Header and responsive navigation
- Product catalogue
- Product detail page
- About page
- Projects page
- Contact experience
- Footer
- Loading, empty, error and not-found states

## Required behavior

- Work from mobile through large desktop.
- Keep meaningful keyboard focus states.
- Respect reduced-motion preferences.
- Keep product content in `src/mocks`.
- Use the product service rather than importing mock arrays into routes.
- Preserve semantic page structure and SEO metadata.

## Out of scope

Database, authentication, CMS, admin dashboard, production enquiry delivery,
backend redesign and production deployment.
