# Emergent Guardrails

Use this repository to develop the approved visual prototype, not to generate a
new full-stack product.

## Preserve

- Next.js App Router
- TypeScript strict mode
- route structure
- mock/API service boundary
- semantic HTML and accessible controls
- loading, error, empty and not-found states

## Do not create

- a database;
- an authentication system;
- an admin dashboard;
- a CMS;
- server-side product management;
- production secrets;
- a replacement backend.

## Visual direction

Create a clean, warm, confident and quietly premium experience. Achieve quality
through typography, spacing, proportion, imagery and subtle interaction. Avoid
3D graphics, WebGL, neon styling, excessive glass effects, animated backgrounds,
scroll hijacking and novelty navigation.

Use the existing GreenNet brand assets once supplied. Do not redesign the logo
or invent a separate identity.
